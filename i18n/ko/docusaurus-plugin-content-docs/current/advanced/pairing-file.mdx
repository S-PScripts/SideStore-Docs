:::warning
iPhone, iPad 또는 iPod touch를 업데이트하거나 초기화하면 페어링 파일이 만료되어 다시 가져와야 해요. 이는 가끔 무작위로 발생하기도 해요. 이는 단순히 Apple 소프트웨어의 작동 방식 때문이며, 현재로서는 이를 해결할 방법이 없어요. 본 가이드에서 iloader를 사용하여 페어링 파일을 수동으로 교체하는 방법을 안내할게요.
:::

## 페어링 파일 교체하기
1. iloader 및 SideStore 설치하고 설정하려면, [설치 전 준비하기](/docs/installation/prerequisites)에 있는 단계들을 제대로 따랐는지 확인해 주세요. 만약 iloader에서 업데이트 여부를 확인하는 창이 나타나면 '확인'을 누르세요.
2. 최상의 결과를 위해 iPhone, iPad 또는 iPod touch를 USB 케이블로 컴퓨터에 연결해 주세요. 하지만 기기가 무선으로만 표시된다면 그것도 괜찮아요.
3. 저장된 페어링 삭제 버튼을 눌러 기존 페어링 파일을 삭제해 주세요.
4. 기기 목록에서 해당 기기를 선택한 다음, 안내 메시지가 표시되면 iDevice에서 '신뢰' 버튼을 누르세요.
5. iLoader로 돌아와서 '페어링 파일 관리'를 클릭해 주세요.
6. "SideStore" 및 원하는 다른 앱 오른쪽에 있는 '배치'를 클릭해 주세요. "페어링 파일 배치 성공!"이라고 초록색 메시지가 표시되어야 해요.
:::note
SideStore에서 여전히 오류가 발생한다면, iDevice와 컴퓨터를 재시동한 후 위의 단계를 다시 시도해 보세요. 그래도 문제가 해결되지 않으면 [디스코드](https://dis.sidestore.io)를 통해 문의해 주세요.
:::
